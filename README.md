# 💰 Personal Expense Tracker

A user-friendly and automated **Personal Expense Tracking System** built using **Google Sheets and Google Apps Script**. This project helps users manage their daily expenses, track spending patterns, analyze financial data, and receive automated email reports.

## 📌 Project Overview

The Personal Expense Tracker simplifies personal finance management by providing an automated platform for recording, organizing, and analyzing expenses.

Users can easily log expenses through interactive prompts, maintain timestamped transaction records, and visualize spending habits through pivot tables and dynamic charts.

## ✨ Key Features

- **Interactive Expense Logging** – Add expenses using custom prompts.
- **Automated Data Tracking** – Automatically records date and time for every transaction.
- **Category-Based Management** – Organize expenses by category.
- **Payment Mode Tracking** – Track expenses based on payment methods.
- **Data Analysis** – Analyze spending using pivot tables.
- **Dynamic Charts** – Visualize expenses through bar charts and pie charts.
- **Automated Email Reports** – Receive expense summaries through email.
- **Custom Menu Integration** – Easy access to expense tracking features.

## 🚀 How to Use

1. Open the Google Sheets project.
2. Navigate to the **Expense Tracker Project** custom menu.
3. Select **Log Expense**.
4. Enter the following details:
   - Category
   - Description
   - Amount
   - Payment Mode
5. Submit the details to record the expense.
6. Click the **Generate Report** button to receive an email summary.
7. Explore the Pivot Tables and Charts tabs to analyze expenses.
